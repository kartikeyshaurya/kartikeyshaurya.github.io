  7. Carrier Vetting Agent — Carrier-vetting SOP as five LangGraph workflows: rules decide, the LLM can only lower a verdict. Prototype

  3. Hybrid Search RAG — Document Q&A that fuses BM25 and vector search, grades retrieved chunks, and ships as a metered API. Production-style MVP

    Problem

    Teams have internal documents (PDFs, Markdown, text files) and want a chatbot that answers from them without making things up. Two failures come up again and again. Dense vector search misses exact terms like product codes, acronyms and error strings. And a model handed loosely related passages will answer confidently anyway.

    Approach

    We started from the two failure modes and treated them as separate problems. For retrieval misses, we ran keyword and semantic search together: dense embeddings for paraphrase, BM25 sparse vectors for exact tokens. The real question was how to merge them. A weighted sum of scores needs normalisation and a tuned weight per corpus, because cosine similarity and BM25 scores live on different scales. Reciprocal Rank Fusion combines the lists by rank instead, so it needs no tuning. Qdrant can store both vectors on the same point and fuse them on the server, which gave us hybrid search in one query and one datastore instead of running a separate search engine.

    For: Built with a colleague · Role: Co-developer, built with a colleague: retrieval, RAG workflow, API and admin portal
    Stack: Python, FastAPI, LangGraph, Qdrant, BM25 (FastEmbed), OpenAI embeddings and GPT-4o mini, PostgreSQL, Redis, React and Ant Design, Docker Compose · Case study →

  4. Brain Response Studio — A serving system and 3D cortex viewer for Meta's TRIBE v2 brain-response model, on one GPU. Working prototype, runs locally

    Problem

    Meta FAIR released TRIBE v2, a research model that predicts fMRI brain activity at about twenty thousand points on the cortex, one frame per second, from video, audio or text. It is released for non-commercial use and ships as a Python library with no product around it. Running it means a gated model download, chaining several large foundation models, tuning GPU memory, and writing NumPy code to make sense of a matrix with twenty thousand columns.

    Approach

    The first constraint was memory. TRIBE v2 chains V-JEPA 2 for video, Wav2Vec-BERT for audio, LLaMA 3.2 for text and WhisperX for transcription, and the video encoder alone didn't fit on an 8 GB GPU at full precision. I didn't want to fork a research library that is still changing, or require bigger hardware, so I applied a few small, documented runtime patches when the model loads: half precision for the video encoder, equal-length windows for long audio so attention memory stays bounded, and reuse of the encoder output when consecutive frames are the same. Each patch is narrow and can be switched off on its own.
